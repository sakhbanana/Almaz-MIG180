# MIG180 Калькулятор подачи проволоки

Android-приложение для полуавтомата **Алмаз MIG180**: расчёт скорости подачи
проволоки **0.8 мм** для стали толщиной **от 0.8 до 5 мм** по заводской
таблице режимов аппарата.

## Что считает

По толщине металла (ползунок 0.8–5.0 мм) приложение показывает:

- скорость подачи проволоки, м/мин
- напряжение, В
- расход защитного газа, л/мин
- подсказки по технике (тонкий металл, разделка кромок, настройка по звуку дуги)

Есть переключатель газа: смесь Ar+CO₂ или чистый CO₂ — для каждого газа своя
таблица подачи и напряжения. Промежуточные толщины интерполируются.

## Где взять APK

Готовый APK собирается автоматически GitHub Actions и публикуется в
[Releases](../../releases) — скачайте `MIG180-WireSpeed.apk` и установите на
телефон (потребуется разрешить установку из неизвестных источников).

## Сборка вручную

```bash
./gradlew assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

Требуется JDK 17 и Android SDK (compileSdk 34).
