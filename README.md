# MIG180 Калькулятор подачи проволоки

Android-приложение для полуавтомата **Алмаз MIG180**: расчёт скорости подачи
проволоки **0.8 мм** для стали толщиной **от 0.8 до 5 мм** по заводской
таблице режимов аппарата.

## Что считает

По толщине металла (ползунок 0.8–5.0 мм) приложение показывает:

- скорость подачи проволоки, м/мин
- показания дисплея аппарата (подача в формате аппарата: 2.6 м/мин → `0260`)
- напряжение, В
- расход защитного газа, л/мин
- подсказки по технике (тонкий металл, разделка кромок, настройка по звуку дуги)

Есть переключатель газа: смесь Ar+CO₂ или чистый CO₂ — для каждого газа своя
таблица подачи и напряжения. По умолчанию выбран чистый CO₂. Промежуточные
толщины интерполируются.

## Где взять APK

APK собираются автоматически GitHub Actions и публикуются в
[Releases](../../releases):

- `MIG180-WireSpeed.apk` — калькулятор по заводской таблице (это приложение);
- `MIG180-Tacho.apk` — оптический тахометр подачи (см. ниже).

Потребуется разрешить установку из неизвестных источников.

## Второе приложение: оптический тахометр подачи

Модуль `tacho` — отдельное приложение «Тахометр подачи» (`MIG180-Tacho.apk`).
Оно не считает по таблице, а **измеряет** реальную скорость: камера смотрит на
метку, нанесённую на подающий ролик, и считает обороты.

### Как пользоваться

1. Нанесите на торец подающего ролика контрастную метку — узкий штрих
   маркером или кусочек изоленты. Чем ýже и контрастнее метка, тем увереннее
   детектор: он ищет всплеск яркости выше адаптивного порога.
2. Закрепите телефон так, чтобы метка проходила через одну и ту же точку кадра.
   При слабом свете включите фонарик.
3. Тапните по метке на превью — вокруг точки появится кольцо ROI. Оно мигает
   на каждом зафиксированном обороте.
4. Смотрите на график яркости внизу: пики должны уверенно пробивать
   пунктирные линии порога. Если не пробивают — метке не хватает контраста
   или ROI стоит не на её траектории.
5. Скорость показывается в м/мин, ниже — об/мин, «см за 20 с» и счётчик
   импульсов. Статус «стабильно» означает, что разброс последних 5 периодов
   меньше 12 %.

### Калибровка — обязательный шаг

Геометрия ролика и проскальзывание проволоки заранее неизвестны, поэтому
приложение не берёт диаметр из справочника, а определяет **эффективную
окружность** экспериментально:

1. Откусите проволоку у наконечника.
2. Запустите подачу и одновременно нажмите «Старт».
3. Через 10–20 секунд остановите подачу и нажмите «Стоп» — приложение покажет
   накопленные обороты с дробной частью (по фазе последнего периода).
4. Измерьте линейкой вышедшую проволоку и введите длину в сантиметрах.
5. Приложение посчитает `C = длина / обороты`, покажет эквивалентный диаметр
   `C / π` и отклонение от геометрического диаметра.

До первой калибровки используется диаметр 29,30 мм (C = 92,05 мм). Окружность,
диаметр и поправочный коэффициент можно ввести и вручную; кнопка «сбросить к
геометрии» возвращает `C = π · D`. Всё хранится в DataStore и переживает
перезапуск.

### Журнал

Кнопка «Записать точку» сохраняет текущую скорость вместе с произвольной
меткой — например, показанием регулятора на дисплее аппарата. Так набирается
таблица «уставка → м/мин». Журнал экспортируется в CSV (разделитель `;`,
десятичная запятая, UTF-8 с BOM — открывается в Excel без плясок).

### Как это устроено

- `ImageAnalysis` в `YUV_420_888`, 1280×720, `STRATEGY_KEEP_ONLY_LATEST`;
  60 к/с запрашиваются через `Camera2Interop` с откатом на то, что умеет камера.
- Читается только Y-плоскость и только внутри круга ROI (r ≈ 16 px) —
  напрямую из `ByteBuffer`, без декодирования в `Bitmap`.
- Порог адаптивный: baseline и модуль отклонения — EMA с α = 0,03, порог
  `max(12, dev · 3,5)`, выход из импульса по гистерезису (0,5 порога),
  дебаунс `max(70 мс, медиана · 0,4)`.
- Период — медиана последних 10 значений (устойчивее среднего к пропускам),
  таймстемпы берутся из `ImageProxy.imageInfo.timestamp`, а не из системных часов.
- Вся обработка кадра — на отдельном исполнителе; в UI состояние отдаётся
  не чаще ~30 раз в секунду.

Требования: Android 8.0+ (minSdk 26), камера. Сети приложение не использует.

## Сборка вручную

```bash
./gradlew assembleRelease
# калькулятор: app/build/outputs/apk/release/app-release.apk
# тахометр:    tacho/build/outputs/apk/release/tacho-release.apk
```

Debug-сборка тахометра и установка на телефон:

```bash
./gradlew :tacho:assembleDebug
adb install -r tacho/build/outputs/apk/debug/tacho-debug.apk
```

Юнит-тесты логики тахометра (детектор импульсов, расчёт скорости, маппинг ROI):

```bash
./gradlew :tacho:testReleaseUnitTest
```

Требуется JDK 17 и Android SDK (compileSdk 34).
